## 🛠️ Details by Module

### 1. 🐚 Bash Scripts (ash-scripts/)
Contains 50 shell scripts demonstrating:
* Mathematical calculations (Armstrong numbers, Fibonacci series, Prime number ranges, LCM/HCF, Factorials).
* Array operations, string manipulations, and palindrome checking.
* Number and character pattern printing.

### 2. ☕ Java (java/)
* **Data Structures:** Custom implementations of Binary Search Tree (BST), Doubly Linked List, Singly Linked List, Stacks, and Queues.
* **Concurrency:** Multithreading demos, thread synchronization, thread safe stack, bounded buffer (Producer-Consumer).
* **Object-Oriented Programming:** Interfaces, dynamic method dispatch, inheritance, exception handling.
* **Timetable Scheduler:** A genetic algorithm-based timetable scheduling engine.

### 3. 🌐 NetBeans Projects (
etbeans-projects/)
Java EE and Web Engineering projects including:
* Servlet implementations (FirstServlet, SecondServlet, FormProject).
* JSP session and state management (Cookie, Number of visitors, AutoRefresh).
* Database connectivity (JDBC MySQL integration).

### 4. 🐍 Python (python/)
* Assignments covering fundamental algorithms, loops, conditionals, and functions (1q1 to 3q15).
* Custom Data Structures and Algorithms library (SingleLinkedList, Stack, Quicksort, Searching).
* Database connectivity (Python oracle connection.py).

### 5. 🧠 Prolog (prolog/)
AI and logic programming laboratory exercises:
* List manipulations (insert nth, delete nth, append, length, search).
* Arithmetic rules (max of numbers, factorial, sum of elements).

### 6. 📊 R Programming (-programming/)
* Searching algorithms (Linear search, Binary search).
* Matrix operations (addition, subtraction, multiplication).
* Statistical functions (mean, median, mode, running totals).
